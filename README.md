HR talent acquisition Tarot

CMoney 招募互動體驗
「AI 禪卡 · 思維決策」設計說明文件
與 AI 同行，用決策創造價值——這是 CMoney 前往未來的唯一方向。


一、這個頁面的用意
這不是一張普通的招募網頁，而是一個埋在招募博覽會現場的「軟性轉換裝置」。它的完整設計意圖如下：

情境起點——博覽會現場的一次掃碼。 求職者在攤位上掃描 QR Code，帶著好奇打開這個頁面。在人潮、攤位、傳單彼此競爭注意力的現場，傳統的「我們有什麼福利」式招募talk很難留下記憶。我們選擇用一個互動儀式——抽一張禪卡——在三十秒內抓住他的注意力。

軟性黏著——用體驗代替說教。 求職者點開牌堆、抽出一張牌、翻開、讀到一段關於「AI 如何放大人的思維」的洞見，以及一個關於自我超越的提問。這個過程不推銷職缺，而是讓他先體驗 CMoney 看待工作與 AI 的方式。當企業文化以「被親身體驗」而非「被告知」的形式進入求職者內心，黏著力遠高於條列式的公司介紹。

內心切入——讓文化先於職缺抵達。 一般招募流程是「先看到職缺 → 再了解文化」。這個頁面把順序反過來：文化與價值觀在第一個觸點就切入求職者的內心，等他真正被理念打動、產生「這就是我想工作的方式」的認同後，才引導他前往 104 投遞。先認同、後投遞，候選人品質與動機都更高。

順暢轉換——通往 104 招募平台。 當求職者被體驗打動，頁面以一個帶有儀式感的中繼頁（「第 79 張，由你親手翻開」）引導他點擊前往 104 全曜財經的徵才頁完成投遞。轉換動作被包裝成「成為自己決策師父的第一步」，而非生硬的「立即應徵」。

全程可追溯——每一步都是數據。 從掃碼進站（瀏覽）、抽卡（互動）、點擊投遞（意圖）、到前往 104（決心轉換），四個關鍵節點全部埋有追蹤事件，搭配 104 端的自訂應徵問題，形成從「一次掃碼」到「一份履歷」的完整、可被量化的轉換漏斗。這讓招募活動的成效不再是「感覺很熱鬧」，而是可被計算 ROI 的投資。


二、核心設計理念
為什麼是奧修禪卡？
奧修禪卡（Osho Zen Tarot）共 79 張——傳統塔羅的 78 張，加上獨有的第 79 張「師父（The Master）」。它與一般塔羅最大的不同在於：它不預測命運，只提供「觀看當下的視角」。它不告訴你答案，而是讓你從一個你原本沒想到的角度，重新看見自己的處境。

這個特質，與我們想傳達的 AI 觀完全吻合。
AI 是 79 種專家思維，而決策是人最終的產出
CMoney 對 AI 的信念是：AI 不是答案的販賣機，而是思維的放大器。

一副禪卡的 78 張，就像 AI 能提供的 78 種專家視角——它能從行銷、財務、工程、心理等無數角度，給你看待問題的不同方式。
但真正決定行動的，是第 79 張：師父牌——也就是掌握自己思維、不被工具奴役的「你」。
AI 給視角，人做決策。思維決策的過程，才是我們最終的行動產出。

這就是為什麼整個體驗的高潮，是抽到第 79 張師父牌時揭曉的主張：「與 AI 同行，用決策創造價值。」

proceed_to_104 與 104 實際投遞數的落差（72 → 35），反映「跳轉後在 104 註冊/登入流程的流失」，是日後與 104 窗口協商簡化應徵流程的數據籌碼，也是 Source ROI 模型中最真實的轉換分母。
上線前必做設定
填入 GA4 ID：開啟 HTML，搜尋 CMONEY_GA4_ID，填入 G- 開頭的評估 ID（未填則自動降級為 console 紀錄，不影響體驗，但拿不到數據）。
部署到公開網址：放上有網域的環境（公司官網子頁、Vercel、Netlify 等），QR Code 才連得到；file:// 本機開啟不會回傳數據。
設定 104 自訂問題：依上述文案在 104 後台新增必填問題。
GA4 設關鍵事件與漏斗報表：將四個事件標記為關鍵事件，在「探索 → 漏斗探索」依序排列，自動計算各層流失率。
產生 QR Code：指向部署後的網址，建議網址帶 utm_source=jobfair，可與其他來源區分。

七、檔案與技術
單一 HTML 檔，self-contained（React + Tailwind via CDN，LOGO 與 79 張牌資料內嵌），雙擊即開、手機優先。
所有幾何圖形為程式生成 SVG，向量銳利、任意尺寸不失真、零外部圖檔依賴。
抽牌不重複，直到 79 張抽完才重新洗牌。
無使用 localStorage／sessionStorage，狀態以 React state 管理。
